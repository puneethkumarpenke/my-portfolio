# Puneeth Kumar Penke — Portfolio

A responsive static portfolio built from the information in Puneeth Kumar Penke's resume.

## Files
- `index.html` — portfolio page
- `styles.css` — responsive design and animations
- `script.js` — mobile navigation + reveal animations
- `Puneeth_Kumar_Penke_Resume2.pdf` — resume copy (optional)

## Run locally
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `puneeth-portfolio`.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. After GitHub finishes deploying, your site will be available at:
   `https://YOUR-USERNAME.github.io/puneeth-portfolio/`
